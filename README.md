# InvoiceExtract

Client-side PDF invoice & receipt extractor.

Drop PDFs or paste text. Extracts vendor, invoice number, date, total and currency entirely in your browser. Nothing is uploaded.

## Why

People on Reddit repeatedly describe spending hours every week doing:

- Download invoice PDF → open → copy vendor / amount / date → paste into spreadsheet → repeat 50 times
- Retype bank statement transactions from PDFs into Excel

This tool automates the extraction step so you can review and export a clean CSV in seconds.

## Features

- Drag & drop multiple PDFs
- Paste raw text
- Heuristic extraction (no AI required)
- Editable results table
- Download or copy CSV
- 100% client-side (pdf.js)

## Usage

Open `index.html` in any modern browser.
